现在完成时

英语 · 初中 · 八年级下学期 · 领域 语法 · 八年级下册 第7单元 A Good Read

学什么

能用 have 或 has 加过去分词，表示到现在为止已经发生的事。

掌握标准

  • 能选出语法正确的词或句子
  • 能在句子里用对这个句型

自测一题

我已经读完了这本书。哪一句正确？

查看答案

I have already read this book.

先修知识点

  • 书籍与阅读按 Go for it! 的常见教学顺序，先学「书籍与阅读」，再学「现在完成时」。
  • 规则动词过去式现在完成时的过去分词，规则动词和过去式的 -ed 相同。
  • 不规则动词过去式现在完成时也要用 see、go 这一类不规则动词的过去分词。

学完这个之后

  • 现在完成时的被动语态
  • already 与 yet
  • 读阅读记录
  • ever 与 never
  • for 与 since
  • 过去完成时
  • 一般过去时与现在完成时
